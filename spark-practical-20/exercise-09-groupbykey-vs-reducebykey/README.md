# Exercise 9 — groupByKey vs reduceByKey

## Practical Execution

### 1. Create Pair RDD

Command:

val employees = sc.parallelize(List(
  ("IT", 50000),
  ("HR", 40000),
  ("IT", 60000),
  ("Sales", 45000),
  ("HR", 35000)
))

### 2. groupByKey

Command:

val grouped = employees.groupByKey()

Command:

grouped.collect().sortBy(_._1).foreach {
  case (dept, salaries) => println(dept + " -> " + salaries.toList.sorted)
}

Output:

HR -> List(35000, 40000)
IT -> List(50000, 60000)
Sales -> List(45000)

### 3. Calculate Totals Using groupByKey

Command:

val groupedTotals = grouped.mapValues(_.sum)

Output:

(HR,75000)
(IT,110000)
(Sales,45000)

### 4. reduceByKey

Command:

val reduced = employees.reduceByKey(_ + _)

Output:

(HR,75000)
(IT,110000)
(Sales,45000)

### 5. Result Counts

groupedTotals.count()

Output:

3

reduced.count()

Output:

3

### 6. RDD Lineage

groupByKey lineage was inspected using:

println(grouped.toDebugString)

reduceByKey lineage was inspected using:

println(reduced.toDebugString)

### 7. Spark UI

The Spark Web UI was opened at:

http://localhost:4040

Jobs and stages generated by the operations were verified.

## Practical Result

Both groupByKey and reduceByKey produced the same final department totals.

groupByKey first grouped all values belonging to each key and then the grouped values were summed.

reduceByKey directly combined values belonging to the same key using the addition operation.
