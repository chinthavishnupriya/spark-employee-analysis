# Exercise 20 — DataFrame CSV and Parquet Read/Write

## Practical Execution

### 1. Create Employee Data

Command:

val employeeData = Seq(
  (1, "Alice", "IT", 50000),
  (2, "Bob", "HR", 40000),
  (3, "Charlie", "IT", 60000),
  (4, "David", "Sales", 45000),
  (5, "Eva", "HR", 55000)
)

### 2. Create DataFrame

Command:

val df = employeeData.toDF("id", "name", "department", "salary")

### 3. Display DataFrame

Command:

df.show()

Five employee records were displayed successfully.

### 4. Write DataFrame to CSV

Command:

df.write.mode("overwrite").option("header", "true").csv(
  "file:///home/vishnupriya/my-spark-app/spark-practical-20/exercise-20-dataframe-io/output/csv"
)

CSV output was successfully created.

The output contained:

- _SUCCESS
- 5 CSV part files
- CRC files generated by the local filesystem

### 5. Read CSV

Command:

val csvDF = spark.read.option("header", "true").option("inferSchema", "true").csv(
  "file:///home/vishnupriya/my-spark-app/spark-practical-20/exercise-20-dataframe-io/output/csv"
)

Command:

csvDF.show()

The five employee records were successfully read.

### 6. CSV Schema

Command:

csvDF.printSchema()

Output:

id          integer
name        string
department  string
salary      integer

### 7. Write DataFrame to Parquet

Command:

csvDF.write.mode("overwrite").parquet(
  "file:///home/vishnupriya/my-spark-app/spark-practical-20/exercise-20-dataframe-io/output/parquet"
)

Parquet output was successfully created.

The output contained:

- _SUCCESS
- 5 Snappy-compressed Parquet part files
- CRC files generated by the local filesystem

### 8. Read Parquet

Command:

val parquetDF = spark.read.parquet(
  "file:///home/vishnupriya/my-spark-app/spark-practical-20/exercise-20-dataframe-io/output/parquet"
)

Command:

parquetDF.show()

The five employee records were successfully read from Parquet.

### 9. Parquet Schema

Command:

parquetDF.printSchema()

Output:

id          integer
name        string
department  string
salary      integer

### 10. Filter Parquet Data

Command:

parquetDF.filter("department = 'IT'").show()

Output:

Charlie  IT  60000
Alice    IT  50000

### 11. Count Parquet Records

Command:

parquetDF.count()

Output:

5

## Practical Result

The complete DataFrame file I/O workflow was successfully verified:

DataFrame
    ↓
CSV Write
    ↓
CSV Read
    ↓
DataFrame
    ↓
Parquet Write
    ↓
Parquet Read
    ↓
DataFrame

CSV and Parquet data were successfully written, read, filtered, and validated.
